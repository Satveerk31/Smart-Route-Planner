A **Graph-based Smart Route Planner** developed in **C++** using **Object-Oriented Programming (OOP)** and **Data Structures & Algorithms (DSA)**. The application enables users to create and manage a road network, calculate the shortest route between cities using **Dijkstra's Algorithm**, and explore the graph using **BFS** and **DFS** traversals.

---

# 📖 Overview

Smart Route Planner is a console-based application designed to simulate a road navigation system. Cities are represented as **vertices** and roads as **edges** in a graph.

The project demonstrates practical implementation of:

- Graph Data Structure
- Dijkstra's Algorithm
- Breadth First Search (BFS)
- Depth First Search (DFS)
- File Handling
- STL Containers
- Object-Oriented Programming

# ⚙️ Algorithms Used

| Algorithm | Purpose |
|-----------|---------|
| Dijkstra's Algorithm | Finds the shortest path between two cities |
| Breadth First Search (BFS) | Traverses the graph level by level |
| Depth First Search (DFS) | Traverses the graph depth-wise |

# ▶️ Getting Started

## Clone the Repository

```bash
git clone https://github.com/your-username/Smart-Route-Planner.git
```

## Compile the Project

```bash
g++ main.cpp src/Graph.cpp src/FileManager.cpp src/Menu.cpp -o planner
```

## Run the Application

### Windows

```powershell
.\planner.exe
```

### Linux / macOS

```bash
./planner
```
